# Pilot Spec

## Objetivo

El piloto busca preparar una solución para gestionar aproximadamente 65 alumnos repartidos entre Liga A y Liga B mediante asistencia, elegibilidad, rotación, convocatoria y estadísticas.

## Alcance P0

P0 crea únicamente los cimientos técnicos:

- estructura del repositorio;
- documentación inicial;
- módulos skeleton;
- validaciones básicas;
- reglas permanentes de operación para agentes.

## Fuera de Alcance P0

P0 no implementa motor de convocatoria, elegibilidad, rotación, cálculos reales de asistencia, hojas reales, datos masivos, correos, triggers productivos, Spreadsheet piloto ni despliegue.

## Privacidad

No se deben incluir datos personales reales. Toda prueba o fixture futura deberá usar datos ficticios.
